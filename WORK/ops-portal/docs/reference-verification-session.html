01 · Agenda

Session goal: explain the solution end-to-end

How we turned a Word PhD bibliography into an interactive verification tool — what failed, what we kept, and the optimum Round 3 design you can demo and reuse.

Problem

Hundreds of APA references need fast, clickable checking — Scholar is incomplete; dates may be wrong.

Method

Author + year Scholar queries, CrossRef for dates & publisher links, online fallback when Scholar won’t index.

Deliverable

Self-hosted HTML table with filters, scores, date flags, and a human review column.

Privacy: this session documents method only — citation text & private lookup cache are not published here.
02 · Problem

From a Word list to a checkable verification UI

Requirements

  • Extract all references from .docx
  • One-click open for each item
  • Score how trustworthy the link is
  • Classify book vs article (and more)
  • Flag missing / wrong years
  • Let the author mark Checked OK

Constraints

  • Google Scholar has no public batch API
  • Scraping hits rate limits fast
  • Many items are web/reports — not on Scholar
  • Author may have missed some dates
  • Must stay reproducible offline for the HTML

03 · Iteration

Three rounds — only Round 3 is the session “final”

Round 1 — DOI → Scholar Superseded

OpenAlex/CrossRef find DOIs → scholar?q=doi:…. Good for journals; weaker for books/web; not what the author wanted as the primary open path.

Round 2 — Author + year Scholar Base

Links built as author surname(s) + as_ylo/as_yhi=year. Type badges (Article/Book/…). Fixed filters. Still assumed Scholar coverage.

Round 3 — Optimum path Current

Author+year Scholar when likely; Online link (URL/DOI/publisher/search) when not; Date check vs CrossRef; Auto status + Your review columns.

04 · Rejected paths

Why scraping Scholar was not the answer

Tried · scholarly scraper

  • Worked for 1–few queries
  • Batch → MaxTriesExceededException
  • ~30s/ref → hours for 500+
  • Against ToS / fragile HTML

Tried · Semantic Scholar API

  • Quick validation idea
  • HTTP 429 without paid quota
  • Not reliable for full library pass

Kept · Free bibliographic APIs + constructed URLs

Use CrossRef (publisher metadata + DOI + year) and optional OpenAlex when budget allows. Never depend on scraping Scholar HTML. Build Scholar links we control; add online fallbacks ourselves.

06 · Linking logic

Two doors: Scholar when useful, web when not

Google Scholar URL shape

https://scholar.google.com/scholar?q=Abels+Bieling&hl=en&as_ylo=2024&as_yhi=2024
  • Primary query = first 1–2 author surnames (or institution name)
  • Year locked with as_ylo / as_yhi
  • Used for Articles / Books / Chapters when Scholar is plausible
  • Shown as “Not on Scholar” for Web / Report / weak matches → force Online link

Online link priority

DOI in citation→ Specific URL in citation→ CrossRef publisher / DOI→ site:domain search→ Google search

Generic homepage URLs (e.g. bare news domain) are skipped in favor of a targeted site search.

Year check (author may have missed dates)

  • Year OK CrossRef year matches citation
  • Check year ±1 year off
  • Mismatch / missing larger gap or no year
  • Verify manually web/gray lit with weak metadata (avoid false alarms)

Auto status

Likely OK strong metadata + year OK

Needs checkup weak match, year issue, gray lit, or multi-works same year

Your review (human)

✓ Checked — OK · ⚠ Needs checkup · ✗ Needs fixing

Saved in browser localStorage; exportable CSV.

08 · Code deep-dive A

Reading Word, parsing APA, building Scholar links

From build_scholar_author_year_html.py — the optimum generator.

Why

.docx is a ZIP. We unzip word/document.xml and concatenate text nodes per paragraph — no Microsoft Word / python-docx needed for input.

def extract_docx_paragraphs(path): with zipfile.ZipFile(path) as zf: xml = zf.read("word/document.xml") root = ET.fromstring(xml) paras = [] for p in root.iter("{...}p"): # each Word paragraph texts = [t.text for t in p.iter("{...}t") if t.text] line = "".join(texts).strip() if line and line.lower() != "references": paras.append(line) return paras # → list of citation strings
Why

Normalize every citation into structured fields used later for URLs, type, and CrossRef. APA-ish: Authors (Year). Title. Rest…

REF_RE = re.compile( r"^(.+?)\s*\((\d{4}[a-z]?)(?:,\s[^)]+)?\)\.\s*(.+)$" ) # groups: authors | year | rest-of-citation def parse_reference(ref): m = REF_RE.match(ref) authors, year, rest = m.group(1), m.group(2), m.group(3) title = rest.split(". ")[0].rstrip(".") surnames = extract_surnames(authors) # ["Abels", "Bieling"] return { "author_label": ", ".join(surnames[:3]), "year": re.sub(r"[a-z]$", "", year), # 2014a → 2014 "title": title, "source_url": URL_RE.findall(ref)[-1:] or None, "doi_in_text": DOI_RE.search(ref), }
Why

No scraping. We construct a Google Scholar search that locks the publication year with as_ylo / as_yhi — author surname(s) only, as requested.

def scholar_author_year_link(parsed): q = " ".join(parsed["surnames"][:2]) # e.g. "Abels Bieling" params = {"q": q, "hl": "en"} if parsed["year"]: params["as_ylo"] = parsed["year"] params["as_yhi"] = parsed["year"] # lock year range return "https://scholar.google.com/scholar?" + urlencode(params) # Result example: # .../scholar?q=Abels+Bieling&hl=en&as_ylo=2024&as_yhi=2024
Why

Book vs article badge in the HTML. Heuristics on volume patterns, publisher names, “In … (Ed.)”, URL / press markers.

def classify_type(ref, parsed): if CHAPTER_RE.search(ref): return "Chapter" if is_webish(ref): return "Web" if is_reportish(ref): return "Report" if JOURNAL_VOL_RE.search(ref): return "Article" # , 58(4), … if has_book_publisher(ref): return "Book" return "Other"
09 · Code deep-dive B

Validation, online fallback, and HTML filters

Why

Metadata without scraping Scholar. CrossRef returns candidate works; we score titles with SequenceMatcher and keep the best match + published year + DOI/URL.

def lookup_crossref(parsed, year_filter=None): params = { "query.title": parsed["title"][:120], "query.author": " ".join(parsed["surnames"][:2]), "rows": 8, } if year_filter: # optional: lock to cited year params["filter"] = f"from-pub-date:{year_filter},until-pub-date:{year_filter}" r = SESSION.get("https://api.crossref.org/works", params=params) items = r.json()["message"]["items"] # pick max similarity(parsed["title"], item["title"][0]) return best # {title, score, doi, url, pub_year}
Why

Author may have missed or mistyped a date. Compare citation year to CrossRef’s published year; soften checks for web/gray literature (weak matches cause false alarms).

def validate_year(cited_year, meta_year): if not cited_year: return "missing", "No year in citation" if not meta_year: return "unverified", "Year not confirmed online" if cited_year == meta_year: return "ok", f"Year OK ({cited_year})" diff = abs(int(cited_year) - int(meta_year)) if diff == 1: return "check", f"Check year — online={meta_year}" return "mismatch", f"Year mismatch — online={meta_year}"
Why

Not everything is on Google Scholar (press, gov, corp PDFs). Priority ladder builds a usable open URL; generic home pages become a site:domain search.

def find_online_link(parsed, meta_cited, meta_any): if parsed["doi_in_text"]: return f"https://doi.org/{doi}", "DOI (in citation)" if specific_url(parsed["source_url"]): return source_url, "URL in citation" if meta_cited and meta_cited["score"] >= 0.65: return meta_cited["url"] or doi_org(meta_cited) if is_generic_url(source_url): return google(f'site:{domain} "{title}" {year}') return google_search_link(parsed) # last resort
